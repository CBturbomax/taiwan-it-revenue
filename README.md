# 대만 IT 월매출 대시보드

대만 상장(TWSE)·상장OTC(TPEx) 전자·IT 기업의 **월별 영업수익**을 모아
단일 HTML 대시보드로 만드는 도구입니다.

**📊 대시보드: https://cbturbomax.github.io/taiwan-it-revenue/**

대만은 상장사가 매출을 **월 단위로** 공시합니다(익월 10일 마감). 분기 실적을
기다리지 않고 AI 서버 공급망의 수요 변화를 한 달 단위로 볼 수 있다는 뜻이고,
이 프로젝트는 그 데이터를 부품 공급망 관점으로 재편성합니다.

---

## 무엇을 보여주나

기준월은 **가장 최근 완결월**로 자동 고정됩니다. 아직 공시가 진행 중인 달은
맨 위 「조기공시분」에만 나오고 다른 수치에는 섞이지 않습니다.

| 섹션 | 내용 |
|---|---|
| 1. 부품군별 종목 차트 | 23개 부품군 113종목, 종목당 36개월 막대(매출)+선(YoY·MoM). 클릭하면 전체 이력 월별 상세표 |
| 2. 부품군 히트맵 | 부품군 × 24개월. YoY / MoM 탭 전환 |
| 3. 변곡 점검 | 역성장 / 시퀀셜 둔화 / 성장 지속 3분류 |
| 4. 조기공시분 | 공시 진행 중인 달의 발표 현황과 마감일 |
| 5. 종목 표 | 949종목. 검색·정렬·필터, 종목 클릭 시 상세 모달 |
| 6. Top movers | YoY·MoM 상하위 5종목 |

### 왜 공식 업종분류를 안 쓰나

대만 공식 분류로는 파워(2308 델타)와 서버 랙 레일(2059 킹슬라이드)이 똑같이
「전자부품업」으로 묶여 공급망 흐름이 보이지 않습니다. 그래서 **AI 서버 한 대에
들어가는 부품 기준**으로 다시 묶었습니다 — AI 파운드리 / 메모리 / 서버 ODM /
ABF 기판 / CCL·소재 / 파워 / 쿨링 / 광통신 / 장비·공정소재 등 23개 부품군.

편성은 [`bom_groups.py`](bom_groups.py)에서 손으로 관리합니다.

## 데이터 출처

| 용도 | 출처 |
|---|---|
| 당월분 (상장) | TWSE OpenAPI `t187ap05_L` |
| 당월분 (상장OTC) | TPEx OpenAPI `mopsfin_t187ap05_O` |
| 과거 이력 | MOPS `t21sc03_{민국연도}_{월}_{0\|1}.html` (Big5) |
| 종목 기본정보 | TWSE `t187ap03_L` / TPEx `mopsfin_t187ap03_O` |

- **원본 단위는 천 NTD**(千元)입니다. DB에 그대로 저장하고 화면에서만 백만
  NTD로 나눕니다. 컬럼명에 `_k` 접미사를 붙여 이중환산을 막았습니다.
- 백필 범위는 2022-07부터입니다. 차트 구간(36개월)의 첫 달도 자체 이력으로
  YoY를 계산하기 위해 12개월 여유를 둡니다.
- 과거 페이지는 `big5`가 아니라 **`cp950`**으로 디코딩합니다. 순수 Big5에 없는
  한자(宏碁·安碁의 `碁` 등)에서 2바이트 스트림이 어긋나 종목명 전체가
  깨집니다.

### 계산 규칙

- YoY·MoM·누계YoY는 **DB에 저장하지 않고** build 시점에 매번 재계산합니다.
- 전년동월 자료가 없으면 0이 아닌 **빈칸**입니다.
- 누계YoY는 회사가 신고한 누계영업수익(당월) ÷ 누계영업수익(전년 동월) - 1.
- 부품군 합계 YoY·MoM은 **like-for-like** — 당월과 비교월 양쪽에 자료가 있는
  종목만 합산합니다. 중간 상장 종목이 만드는 가짜 급등을 제거합니다.
- 모회사가 자회사를 연결하는 경우 합계에서 자회사를 뺍니다
  (`CONSOL_PARENT`).

## 갱신 주기

`run.bat`을 실행하면 5단계가 순서대로 돕니다.

```
[1/5] 종목 기본정보    매 실행
[2/5] 매출 데이터      최근 3개월 + 당월 API (정정공시 반영)
[3/5] 한글 종목명      names_auto.py 재생성
[4/5] dashboard.html   빌드
[5/5] gh-pages 배포    force push
```

```bat
run.bat              평시 (최근 3개월 갱신)
run.bat backfill     전체 재적재 (2022-07부터)
```

대만 공시 마감이 **익월 10일**이라 매월 1~10일에 데이터가 채워집니다. 그 기간엔
하루 한 번 이상 돌리면 좋습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `fetch.py` | 원본 수집 → SQLite (`data.db`). 백필·일일갱신·종목마스터 |
| `build.py` | `data.db` → `dashboard.html` (단일 파일, 차트 라이브러리 없이 SVG 직접 생성) |
| `bom_groups.py` | 부품군 편성, 종목별 사업 설명, 연결 모자관계 |
| `groups.py` | IT 업종 필터, 화면 표기, 임계값 |
| `names.py` | 손으로 정한 한글 종목명 (최우선) |
| `names_auto.py` | 한자 음독 자동 변환 결과 (생성 파일) |
| `hanja_kr.py` | 한자→한글 음독표 593자 + 두음법칙 |
| `gen_names_auto.py` | `names_auto.py` 생성기 |
| `audit_cjk.py` | 화면에 남은 한자 검사 |
| `run.bat` | 위 5단계 실행 |

`data.db`는 저장소에 없습니다(17.6MB, 매일 변경). 처음 쓰는 사람은:

```bat
run.bat backfill
```

## 필요 환경

- Python 3.10+ (표준 라이브러리만 사용, 외부 패키지 없음)
- Windows (`run.bat`). 다른 OS에서는 `fetch.py` → `gen_names_auto.py` →
  `build.py`를 직접 실행하면 됩니다.

## 주의사항

- **대시보드의 수치는 회사가 공시한 매출 원본**이며, 투자 판단이나 권유가
  아닙니다.
- 마감일 계산은 주말 순연만 반영합니다. **대만 공휴일 순연은 미반영**입니다.
- 발표일 추적은 이 기능이 들어간 시점부터 쌓입니다. 그 이전 데이터의 발표일은
  알 수 없어 `—`로 표시됩니다.
